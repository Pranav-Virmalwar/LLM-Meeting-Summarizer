# LLM Meeting Summarizer

A Streamlit web app that converts `.txt` and WebVTT (`.vtt`) meeting transcripts into concise summaries with OpenAI chat models.

## Purpose

Long transcripts make it difficult to quickly identify themes, decisions, and follow-up work. The app splits a transcript into manageable segments, summarizes each segment, and combines the results into one meeting overview.

## Features

- Upload plain-text or WebVTT meeting transcripts.
- Summarize long transcripts with a map-reduce LLM workflow.
- Use default prompts or supply extraction and synthesis instructions.
- Keep API credentials outside the source code using an environment variable.

## Technology and workflow

- Python and Streamlit for the interface.
- LangChain and OpenAI chat models for summarization.
- `webvtt-py` for caption parsing and `tiktoken` for text splitting.

`Transcript upload → text extraction → token-aware chunks → per-chunk summaries → combined meeting summary`

## Prerequisites

- Python 3.9 or newer.
- An OpenAI API key with access to the configured model.

## Setup and run

```bash
git clone https://github.com/Pranav-Virmalwar/LLM-Meeting-Summarizer.git
cd LLM-Meeting-Summarizer
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export OPENAI_API_KEY="your_api_key_here"  # Windows PowerShell: $env:OPENAI_API_KEY="your_api_key_here"
streamlit run app.py
```

Do not add your key to `app.py`, a commit, or an issue. `.env.example` shows the required variable name, but the app reads `OPENAI_API_KEY` from the environment.

## Usage

1. Open the local URL printed by Streamlit.
2. Upload a `.txt` or `.vtt` transcript.
3. Optionally provide extraction or synthesis instructions.
4. Select **Generate summary**.

The result is generated by an external OpenAI service. Avoid uploading confidential meeting information unless doing so complies with your organization's data-handling policy.

## Validation

```bash
python -m py_compile app.py
```

## Limitations and future work

- Quality depends on the transcript and selected model; API usage can incur OpenAI charges.
- WebVTT speaker metadata is not preserved as structured data.
- No automated test suite is currently included.
- Future work: transcript redaction, automated parser tests, model selection, and downloadable summaries.
